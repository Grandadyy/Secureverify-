How Verification Works

1
Your device sends the scanned QR code data (Product ID + SHA-256 hash) to our secure verification server via HTTPS/TLS 1.3
2
The server retrieves the registered product record from the MySQL database and recomputes the expected SHA-256 hash
3
The received hash is compared with the recomputed hash using constant-time comparison to prevent timing attacks
4
Scan count is checked against the anomaly threshold. Result is returned in under 1.5 seconds with full audit log entry
